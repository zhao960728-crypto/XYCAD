# 功能缺陷与限制

更新：2026-11-07。本项目目前仅供应急预览与辅助核对，仍在持续做格式兼容和功能完善。请结合原 CAD、原始单位和正式审核判断；界面打开成功、测试通过或 CAD AUDIT 无错误，均不等于模型完整、尺寸正确或可直接制造。

## 兼容性与显示

- DWG/DWT 只适配已列版本的常见二维模型空间。布局、复杂代理、OLE、外部参照和三维实体不完整。失败时可能仅显示保存的栅格内嵌图，不能在此基础上声称可测量或完整矢量转换。DXF 为部分实现，图案填充、复杂线型、MTEXT 和尺寸降级可能改变显示。
- SHX、大字体用系统字体替代，字形、换行、文字位置可能不同。缺少保存标注块时只近似重建部分线性尺寸；其他类型可能无法重建。表格优先读保存图形块，不等于恢复原生参数表格。
- EXB 仅覆盖部分模型流对象和版本；无 DXF 导出。DWFx 以打印页为单位，最多 64 页，嵌入字体、图片、复杂画笔及经典 DWF 不完整。
- SLDDRW 依赖原件保存的视图缓存，不能自动重建缺失视图。部分文件只显示图框或部分矢量。DXF 导出拆分尺寸文字与线条，失去原生标注关联；缺视图/页归属不可靠时禁用整套 DXF。PDF 是否可用也取决于保存页面。
- STEP 和 X_T/X_B 不是完整 CAD 内核。复杂修剪、曲面交线、自由曲面、旧版本布局、二进制编码和容差可能导致缺面、缺件、失败或慢解析。装配树的未读出节点应视为缺件提示；能打开不代表全模型可用。IGES/IGS、SLDASM 不在当前范围内。
- OBJ/PLY/OFF/STL/3MF 侧重支持的网格和结构，没有完整材质、贴图和 CAD 特征语义。未声明单位时保留原坐标；不得自行假定毫米。

## SLDPRT 的具体缺陷

需另配 Python 及 `sldprt2step`，其代码未捆绑。仅处理已适配容器中所选配置保存的实心几何；每配置最多 256 个实体，输入最多 64 MiB。未实现通用特征历史/增量记录重放，不提供参数特征编辑、自动重建、装配约束或通用钣金展开。

旧式 OLE、非恒等实体变换、片体、部分容差边与复杂曲面尚未完整支持；配置可能只有名称而没有可读取的保存几何。检测到实体不完整或轻量缓存外形明显冲突会拒绝成功预览。外形检查仅为粗查，不能发现全部孔位、内部形状或历史变化。不能用成形配置冒充展开配置。

既有固定批次默认配置仅 33/78 可预览；另一批 22 份原件的 35 个配置状态中，11 个状态成功、9 份至少一个配置成功。这些是本机样本记录，不是所有 SLDPRT 的覆盖率。详见[验证范围](project-regression.md)。

## 测量与出图精度

- 三维取点、孔径拟合、平面间距和三视图来自网格，受离散精度、选点、容差和可读几何影响。曲面三角形有自己的法向，不能当作真实基准平面。
- 二维图纸页测量需正确设置当前视图比例，同页不同视图可能不同。单位未声明时无法保证物理尺寸换算。
- 三视图为第一角法预览投影和可编辑线段，不保留原生特征、关联标注、公差、工艺或自动布局语义。上限 20 万三角面，并有遮挡计算预算；可能拒绝大模型。部分可读装配禁用整套出图，即使可单独导出完整节点，也不能据此确认全装配。

## 性能与部署

以下文件、解压量、页数、实体、网格与时间上限的原因见[输入与资源上限说明](resource-limits.md)。它们是当前程序的资源与复杂度保护值，不是对应格式本身的限制；改变数字不代表兼容性或精度同步提高。

- 没有统一上传大小门槛，不等于无限大小。DWG 解压与 DXF 转换输出等预算为 256 MiB，DWG 索引上限 100 万条；3MF/DWFx/EXB 解压也有独立预算。页数、实体数、几何求值和超时另行限制。
- 共享网格路径最多处理 500 万个不同零件网格三角面，单件最多 100 万面；旧的整场景路径最多展开 50 万面。首帧仍需等待服务端建立结构和网格，按需加载不能消除解析成本。大模型可耗费数十秒至数分钟和大量内存，仍可能不完整。
- 独立服务默认回环监听，没有完整用户注册、计费、配额和多租户权限系统。公网部署需自行接入认证、HTTPS、请求约束及资源隔离。
- 本机 Windows 验证不等于 Linux/macOS、所有浏览器或公网并发验证。WebGL 2 和可选 Python 入口各有额外环境要求。
- 装配派生网格会暂存，闲置约 30 分钟失效；容量回收或服务重启后需重新上传。项目未提供永久 CAD 文件库。
